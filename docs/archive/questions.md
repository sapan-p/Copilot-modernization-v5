# Question bank: archive

Answered and closed questions that nothing in `docs/` or `modern/` rests on any more, moved
here word for word from [../questions.md](../questions.md) by `/mod-answer archive`. Their
IDs still count: code comments, plans and notes that cite one find it here. Nothing here is
edited; a question that's reopened (`/mod-answer Q-###: <new answer>`) moves back to
`questions.md`.

Each run adds a section: `## Archived YYYY-MM-DD`, with the same columns as `questions.md`.
