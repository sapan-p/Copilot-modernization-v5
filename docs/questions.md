# Question bank

Everything the code couldn't tell us. Work never waits for an answer: each OPEN question has
a working assumption, used until someone answers.

- **Kind:** Technical · Functional · Data · Integration · Operations
- **Ask:** Developer · Business · Ops · DBA · Vendor
- **Risk if wrong:** H (changes scope, design or data) · M (changes one component) · L (a detail)
- **Status:** OPEN (also when partly answered: the working assumption says what's known) ·
  ANSWERED · CLOSED (no longer relevant; say why in the Answer column)

Write the question so the person asked can answer it without the code: what we need to know,
and why it matters.

Answer any time: select the **Guide** and run `/mod-answer` to see the open questions, or
`/mod-answer Q-###: <answer>`. It shows what the answer changes, and records it once you
accept.
